# Quantum Machine Learning on Node-Feature Graphs Using Neutral-Atom Simulations

This repository provides the implementation for our paper accepted at the 2026 IEEE 2nd International Conference on Quantum Artificial Intelligence (QAI). It includes the complete pipeline for dataset preprocessing, quantum kernel, quantum simulations using Pasqal's Pulser library, and the classical baselines.

The repository is structured to isolate the various phases of the experiment. The layout optimization and data conversion are handled in `construct_graph.py` and `transform_all_with_repulsion.py`. The quantum simulation and measure extraction are managed through `quantum_core.py`, `pulser_functions.py`, and `quantum_measures.py`. Finally, the complete learning curves for quantum and classical models are executed with their respective learning curve scripts.

## Graph Preprocessing

A crucial step in mapping node-attributed graphs to neutral atoms is respecting the geometric constraints of the optical tweezers while preserving the graph topology. We implemented a custom spring-relaxation algorithm to determine the atomic positions. To guarantee that unconnected nodes do not accidentally interact and alter the encoded structure, the algorithm applies an explicit repulsive force to all non-adjacent pairs. This ensures their final spatial separation strictly exceeds the Rydberg blockade radius (approx. 8.0 μm), while connected nodes converge to a target distance between 4.5 and 6.0 μm. Graphs failing to meet spatial constraints (e.g., radius > 50 μm or excessive MSE) are filtered out.

## Quantum Kernel 

The quantum model simulates a three-level neutral-atom system. Continuous node features are encoded directly into the hyperfine ground states using local Raman laser pulses (Blackman waveform, 800 ns). Graph connectivity is subsequently enforced via a global Rydberg laser pulse (maximum Rabi frequency of 4π rad/μs and a constant detuning of 0.2 rad/μs) that generates entanglement based on the previously computed spatial layout. 

The evolution time was set to 240.1 ns. To strictly prevent data leakage, this parameter was determined empirically to maximize entanglement generation using an independent 200-sample subset of the MNIST training data, keeping the test set isolated. Following the evolution, we extract occupation and correlation distributions using 500 measurement shots per circuit, which are then compared using the combination of multiple kernels generated by the exponential of the 1-Wasserstein distance.

## Classical Baselines Optimization

To ensure a fair and rigorous comparison, we also focused on optimize the classical baselines. For the Weisfeiler-Lehman (WL) kernel, implemented via the GraKeL library, we perform a 3-fold stratified cross-validation on the training subsets to select the number of iterations and the SVM regularization parameter. In the paper, we extended the optimization to also the discretization thresholds for the continuous spatial and angular features.

For the Graph Convolutional Network (GCN), we built a 2-layer architecture with batch normalization and global pooling in PyTorch Geometric. The model is trained using the Adam optimizer and a learning rate scheduler. To prevent overfitting, we apply early stopping by monitoring the loss on a 20% holdout validation split, which is dynamically extracted from the available training pool during each run.

Our evaluation is designed to test the models in a low-data regime while strictly preventing data leakage. The 15-sample-per-class test set is separated at the very beginning of the pipeline and is never exposed to the hyperparameter tuning or feature scaling processes. 

To evaluate stability, we report the mean and standard deviation across five runs for each training size. In each run, a different random seed is used to subsample a new training subset from the main training pool. The pre-computed quantum distributions allow us to efficiently repeat this sampling process and train the SVM classifiers without needing to rerun the computationally expensive quantum simulations.
